演示模式

必须先开启演示模式，才能点「填入演示参数」。 未开启时点「生成视频」走真实接口并扣费（二次确认）。

提交前检查

  • 已选接口与模型，或处于演示模式
  • 图生：已选本地图或图片链接；文生无需图
  • 提示词写清主体 / 动作 / 镜头
  • 成功后尽快「下载视频」（约 24 小时后可能删除）

使用规则

  • 先定接口，再定该接口下的模型 ID
  • 模型列表只属于某个接口，禁止跨站混用
  • 新建接口的模型区为空，需手动添加
  • 请勿反复真实生成（会扣费）

如何使用

  1. 设置：先「添加接口」（Base URL + API Key），再为它添加模型；可建多套接口。
  2. 生成：选接口 → 选模型（真实 model 名）→ 提示词 → 图生再选本地图或链接。
  3. 图生必填图；文生不需要图。
  4. 任务列表只保存记录和链接，不保存视频文件。
  5. 点「下载视频」后会自动保存到「设置 → 下载目录」；约 24 小时后线上文件可能删除，请及时下载。
新建接口模型区为空，只属于新接口；编辑只显示该接口模型。 请求：model / prompt / duration（+图生 input_reference）。

参数说明

接口必选。URL + Key，多套可切换。
模型必选。显示名与接口 model 字段一致。
参考图图生必填：本地上传或 HTTPS URL。文生不传图。
提示词必填。
时长 / 清晰度按所选模型规格选择。

模型从哪里来

  • 模型 ID 由你的视频生成服务商提供（见其文档或模型列表），本项目不内置任何模型。
  • 图生模型通常带 -i2v 字样，生成时必须提供参考图；文生模型只需提示词。
  • 在「设置 → 添加接口 → 该接口的模型」中，把模型 ID、类型、清晰度、单价、时长范围如实填入即可使用。
