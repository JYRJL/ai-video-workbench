# Windows 桌面端（AI 视频工作台）

桌面端 = `main.py`（Python + pywebview 外壳） + `app\index.html`（界面）。
界面改动请改仓库根目录的 `index.html`，然后**同步一份到本目录**：

```bash
# 在仓库根目录执行
copy index.html desktop\app\index.html
```

## 开发运行

1. 安装 [Python 3.10+](https://www.python.org/downloads/)（安装时勾选 **Add python.exe to PATH**）
2. 安装依赖：

   ```
   python -m pip install pywebview
   ```

3. 双击 `开发启动.bat`（或在本目录执行 `python main.py`）

## 配置与数据存放

- 配置（接口 / Key / 任务）保存在 exe 旁边的 `data\app-state.json`
- WebView 数据在 `data\webview\`
- 下载目录记录在 `data\download_dir.txt`，默认 `data\backups`

> ⚠️ `data\` 里含你的 API Key，**不要**把带 `data\` 的目录打包发给别人。

## 打包成免安装 exe（可选）

安装 PyInstaller 后，在本目录执行：

```
python -m pip install pyinstaller
python -m PyInstaller --noconfirm "AI视频工作台.spec"
```

产物在 `dist\AI视频工作台.exe`。分发时把 `exe`、`app\index.html`、
`app-icon.png`、图标和说明文件放同一文件夹即可（**不要**包含 `data\`）。

## 常见问题

- **提示缺少 pywebview**：回到第 2 步安装依赖
- **杀毒软件报毒**：PyInstaller 单文件壳的常见误报，可改用 `--onedir` 或自行签名
