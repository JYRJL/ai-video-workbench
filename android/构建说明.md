# 安卓端（AI 视频工作台）

安卓端 = Capacitor 壳工程。`www\index.html` 是界面（与仓库根目录 `index.html`
同源），`android\` 是 Gradle 工程。

## 环境要求

| 工具 | 版本 | 说明 |
|------|------|------|
| Node.js | 18+ | [下载](https://nodejs.org/) |
| JDK | 21 | [下载](https://adoptium.net/) |
| Android SDK | API 36（build-tools 35） | 通过 Android Studio 安装 |

环境变量（按你的实际安装路径调整）：

```
JAVA_HOME = <JDK 21 路径>
ANDROID_HOME = <Android SDK 路径>
```

## 界面更新流程

改了仓库根目录 `index.html` 后，同步到安卓工程：

```bash
# 1. 覆盖 www（在 android 目录）
copy /Y ..\index.html www\index.html

# 2. 同步进 Gradle 工程（会拷到 android\app\src\main\assets\public\）
npm install
npx cap sync android
```

## 构建 APK

```bash
cd android\android
gradlew.bat assembleDebug
```

产物：`android\app\build\outputs\apk\debug\app-debug.apk`
（debug 签名，可直接侧载安装；上架应用商店需自行配置 release 签名）。

> 工程已开启 `android.overridePathCheck=true`，中文路径可直接构建；
> 若个别插件仍报路径错误，再把 `android\android` 复制到纯英文路径构建。

## 版本号

发新版时同步改两处：
- `android\app\build.gradle` → `versionCode`（+1）/ `versionName`
- 界面内「设置 → 产品信息」的版本号（`index.html`）
